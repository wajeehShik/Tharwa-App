## 🚀 ما هو "ثروة"؟

**ثروة** هو مساعد مالي ذكي يساعدك على التحكم الكامل بأموالك بطريقة بسيطة وواعية.

ليس مجرد تطبيق لتتبع المصروفات…  
بل نظام متكامل يساعدك على **فهم سلوكك المالي، تنظيمه، وتطويره** للوصول إلى استقرار مالي حقيقي.

---

## 🧩 مكونات النظام

- 📱 تطبيق موبايل (Flutter)  
- 🌐 صفحة هبوط (HTML - Tailwind CSS)  
- 🛠️ لوحة تحكم (Laravel)  

---

## ✨ المميزات

### 💸 تتبع المصروفات
- تسجيل المصاريف اليومية بسهولة  
- تصنيف الإنفاق (احتياجات / كماليات)  
- رؤية واضحة لحركتك المالية  

### 💰 إدارة الدخل
- إضافة مصادر دخل متعددة  
- عرض شامل للوضع المالي  

### 🎯 الادخار الذكي
- إنشاء أهداف مالية  
- متابعة التقدم بشكل بصري  

### 🔒 نظام تجميد الأموال
- قفل مبلغ معين لمنع صرفه  
- تعزيز الانضباط وتقليل التبذير  

### 🧾 إدارة الديون
- تسجيل الديون  
- خطط سداد ذكية  
- تنبيهات بالمواعيد  

### 🧠 التحليلات المالية
- تقارير ذكية  
- نصائح مخصصة  
- فهم أعمق لسلوكك المالي  

---

## 🎯 الهدف

هدف "ثروة" ليس فقط إدارة أموالك…  
بل مساعدتك على الوصول إلى:

- الاستقرار المالي  
- تقليل التوتر المرتبط بالمال  
- الحرية المالية على المدى الطويل

## ⚙️ طريقة التشغيل

### 1️⃣ استنساخ المشروع
```bash
git clone https://github.com/your-username/tharwa.git
cd tharwa
```

### 2️⃣ تشغيل Laravel
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### 3️⃣ تشغيل Flutter
```bash
cd mobile
flutter pub get
flutter run
```

## 🚀 أفكار التطوير المستقبلية

نسعى لتطوير "ثروة" ليصبح نظامًا ماليًا ذكيًا متقدمًا يساعد المستخدمين على اتخاذ قرارات مالية أفضل بشكل مستمر.

### 🤖 الذكاء الاصطناعي (AI)
- تقديم اقتراحات مالية ذكية بناءً على سلوك المستخدم  
- تحليل الإنفاق والتنبؤ بالمشاكل المالية قبل حدوثها  
- مساعد مالي شخصي يقدم نصائح مخصصة  

---

### 📊 إحصائيات وتقارير دورية
- تقارير أسبوعية وشهرية عن الأداء المالي  
- متابعة التقدم نحو الأهداف  
- مؤشرات واضحة تساعد في اتخاذ قرارات مالية أفضل  

---

### 🎯 نظام التحفيز (النقاط)
- نظام نقاط يكافئ المستخدم على الالتزام  
- إنجازات تحفيزية (Achievements)  
- تجربة تفاعلية تشجع الاستمرارية  

---

### 💎 الاشتراك الشهري (Premium)
- ميزات متقدمة تعتمد على الذكاء الاصطناعي  
- تقارير احترافية مفصلة  
- أدوات تخطيط مالي متقدمة  
- تجربة محسّنة للمستخدمين
