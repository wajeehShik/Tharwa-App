# 💰 Tharwa - Smart Money Manager

Tharwa is a modern personal finance application designed to help users take full control of their financial life with simplicity and intelligence.

> 🚀 Track. Save. Grow.

---

## 📱 About The Project

Tharwa is more than just an expense tracker — it's a smart financial assistant that helps users understand their spending habits, build savings, and achieve financial freedom.

The app provides a clean and intuitive user experience with powerful features that simplify money management.

---

## ✨ Features

- 📊 Track daily income and expenses بسهولة
- 🧾 Categorize spending (Needs vs Wants)
- 🎯 Set and manage savings goals
- 💳 Monitor debts and loans
- 📈 Smart financial insights and analytics
- ⚡ Fast and user-friendly interface
- 🌙 Clean and modern UI/UX (RTL support)

---

## 🧠 Vision

Our goal with Tharwa is to empower users to:
- Understand their financial behavior
- Build strong saving habits
- Make smarter financial decisions
